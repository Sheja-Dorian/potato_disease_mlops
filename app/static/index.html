Four interpretable features were computed on the leaf pixels of every training image. Together they explain what the CNN has to learn.

1 · Class distribution

2 · Green ratio G/(R+G+B)

3 · Lesion fraction (yellow/brown tissue)

4 · Texture (edge strength)

The story

Colour features (green ratio, lesion fraction) split healthy from diseased leaves. Only texture separates the two blights: early blight's ringed "target" spots against late blight's smooth, dark patches. No single feature separates all three classes, which is why a CNN that learns colour and local texture together works well. The class imbalance means the model is judged on macro-F1, not accuracy alone.

1 · Upload new labelled data

Bulk-upload many images or a .zip. In a zip, the folder names give the labels (early_blight/, healthy/, late_blight/). Loose images use the class you pick below. Images are validated with the training preprocessing and saved to the database.

2 · Trigger retraining

Fine-tunes the current production model on the new data plus a replay sample of the original data, then compares it with the current model on the test set. The new model is promoted only if it is not worse. Retraining also starts automatically when pending uploads reach the threshold.
